# character-deepening/ — Karaktärsfördjupning

Per POV-karaktär och central biperson skapas en fil `char-<id>.md` baserad på `MALL.md`.

**Filen är writer-agentens ledstjärna.** Läses FÖRE varje kapitel där karaktären är POV eller central biperson.

## Innehåll per fil

- En mening om vem karaktären är
- Yttre mål (i plottet)
- Drivkraft (det hen egentligen vill — ofta bakåt-spår från barndom/förlust)
- Sårbarhet (det som gör hen mänsklig)
- Styrkor (som inte är hjältemodiga)
- Quirks (det minnesvärda — kropp i prosan)
- Röst-canon (talspråk, tankespråk, typiska meningar, FÖRBJUDNA konstruktioner)
- Plot-funktion per kapitel
- Anti-mönster (vad karaktären INTE är)
- Risker för writer (specifika fallgropar)

## Disciplin

1. **Röst-canon är icke-förhandlingsbart.** Om filen säger "X är FÖRBJUDET (annan POV signum)", använd inte X för denna karaktär ens om det är mest naturligt.
2. **Quirks ska användas, inte bara listas.**
3. **Sårbarheter ska prickas av ibland — inte hela tiden.**
4. **Anti-mönstren är hårda regler.**

Om character-deepening säger något som motsäger något writer vill skriva — fördjupningen vinner. Eller flagga för uppdatering om canon behöver utvecklas.
