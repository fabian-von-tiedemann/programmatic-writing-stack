# LEARNINGS — Permanent mönster-katalog

Hjärtat i kvalitetsloopen. Varje upptäckt fel — av redaktör, prosa-städ, dialog-coach, NAGELFAREN, förläggare, sensitivity-läsare, läsare — sparas här som **permanent mönster** så att framtida kapitel undviker det.

## Format per inlägg

```
## L-<NNN> — <kort titel>

**Datum:** YYYY-MM-DD
**Källa:** [redaktör | prosa-städ | dialog-coach | NAGELFAREN | förläggare | sensitivity | läsare]
**Plats:** kapitel-NN, rad NN (om relevant)
**Symptom:** vad som skrevs och varför det skar
**Lärdom:** den generella insikten
**Regel:** den operationaliserade regeln (gärna grep:bar)
**Spridning:** vilka roller/briefer ska uppdateras (writer.md, redaktor.md, tics-katalog.md, ...)
```

## Disciplin

1. Varje pass som hittar nytt mönster skapar minst ett L-inlägg.
2. Skriv lärdomen tillräckligt generellt att den fångar **kategori**, inte bara den specifika instansen.
3. Spridning är obligatorisk — om en lärdom inte propageras till roller/briefer kommer den att upprepas.
4. Sorteras kronologiskt (senaste högst eller lägst — välj en konvention och håll den).
