# KAPITELPLAN

> Kapitelvis vad-händer-där. Levande dokument — uppdateras vartefter skrivande och redigering ger insikter.

## Format per kapitel

```
## Kapitel NN — {{kort titel}}

- **POV:** char-<id>
- **Plats(er):** loc-<id>, loc-<id>
- **Tid:** YYYY-MM-DD HH:MM – HH:MM
- **Akt:** [1 | 2 | 3]
- **Plot-funktion:** vad rör sig framåt?
- **Tema-funktion:** vilket tema bärs?
- **Karaktärs-funktion:** vad förändras för POV?
- **Clues planterade:** C-NN, C-NN
- **Clues skördade:** C-NN
- **Knowledge-progression:** vem får veta vad?
- **Cliffhanger:** vad ändrar slutet retroaktivt?
- **Längd:** ~{{NN}} ord
- **Status:** [TBD | utkast | redigerad | klar]
```
