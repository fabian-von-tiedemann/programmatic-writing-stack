# plot/ — Lager 4

> Bokens dramatiska konstruktion. Vad händer, när, i vilken ordning, vem bär bågen, vilka clues planteras + skördas, vilken klocka tickar.

## Filer

### Strukturella
- **`through-line.md`** — bokens centrala dramatiska linje från start till slut
- **`struktur.md`** — Act 1/2/3, vändpunkter, mid-point, klimax
- **`bagar.md`** — karaktärs- och tema-bågar parallellt
- **`kapitelplan.md`** — kapitelvis vad-händer-där

### Konflikt + spänning
- **`inciting-incident.md`** — det som startar boken
- **`antagonist-tidslinje.md`** — antagonistens parallella linje (det som händer "off-screen")
- **`try-fail-cykler.md`** — protagonistens försök + misslyckanden + lärdomar
- **`spanning.md`** — hur spänningen kalibreras
- **`tension-tracker.md`** — per-kapitel spännings-nivå (mätbar)

### Information + tid
- **`cold-open.md`** — bokens första scen (prolog/kapitel 1)
- **`clue-economy.md`** — alla clues: vad planteras + var, vad skördas + var (KRITISK för thriller)
- **`informationsflode.md`** — vem vet vad när (knowledge progression)
- **`klocka.md`** — bokens tickande klocka (deadline, ticking time-bomb)

### Per-scen
- **`scenkort/`** — en MALL.md + en fil per scen som ska skrivas (writer-agentens närmaste arbetshandling)

### Serie (om relevant)
- **`serie/promise.md`** — vad serien lovar över böckerna
- **`serie/canonical-events.md`** — vad är fast canon över böckerna
- **`serie/timeline-of-secrets.md`** — vilken hemlighet avslöjas när

## Designordning

1. Through-line + struktur (Act 1/2/3)
2. Inciting incident + klocka
3. Bågar (karaktär + tema) parallellt
4. Antagonist-tidslinje (vad händer off-screen)
5. Kapitelplan (vad-händer-per-kapitel)
6. Try-fail-cykler (kalibrera protagonist-misslyckanden)
7. Cold open (specifikt designad)
8. Clue economy (allt plant + pay-off — kritisk!)
9. Informationsflöde (knowledge matrix kopplas till plot)
10. Spänning + tension-tracker (kalibrering per kapitel)
11. Scenkort per scen (writer-input)

## Disciplin

- Inget kapitel skrivs utan scenkort
- Clue economy uppdateras varje gång clue planteras/skördas
- Tension-tracker uppdateras per redaktör-pass
