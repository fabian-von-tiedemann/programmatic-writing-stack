# TRY-FAIL-CYKLER

> Protagonistens försök → misslyckanden → lärdomar genom boken. Eskaleringen är dramatisk drivkraft.

## Princip

> Varje försök ska MISSLYCKAS men ge KUNSKAP. Misslyckandet ska tvinga protagonisten närmare antingen sanningen eller sin egen kärnbrist.

## Anti-mönster

- Försök → lyckas direkt = ingen drama
- Försök → misslyckas utan att karaktären lär sig = upprepning
- Försök blir konstant samma typ = monoton
- Lärdomen är medveten reflektion ("hon förstod att..." — författar-essä) — visa via handling istället
