# BESLUTSLOGG

> Alla större beslut i bokprojektet — motivering, datum, alternativ som övervägdes. Levande dokument.

## Format

```
## B-NNN — {{beslut}}

**Datum:** YYYY-MM-DD
**Kategori:** [koncept | plot | karaktär | stil | teknik | förlag | annat]
**Status:** [Beslutat | Reviderat | Avfärdat]

### Beslut

Vad bestämde vi? En mening + utveckling.

### Motivering

Varför? Vilka principer? Vilka data?

### Alternativ som övervägdes

- **Alternativ A:** ... — avfärdat eftersom ...
- **Alternativ B:** ... — avfärdat eftersom ...

### Konsekvenser

Vad får detta beslut för effekt på övriga delar av boken?

### Referenser

- Diskussion i `.context/meta/oppna-fragor.md` (innan beslutet)
- Påverkar: `.context/koncept/X.md`, `.context/plot/Y.md`, ...
```
