# meta/ — Meta-dokumentation om projektet självt

## Filer

- **`beslutslogg.md`** — alla större beslut + motivering
- **`oppna-fragor.md`** — frågor som inte är beslutade ännu
- **`parkering.md`** — idéer/scener/karaktärer som inte används i denna bok (kanske nästa)
- **`hantverksstandarder.md`** — positiva krav på prosans hantverk (kompletterar förbjudna saker)
- **`ambition.md`** — bokens ambitionsnivå — säljmål, kvalitetsmål, hantverksmål

## Underkatalog

- **`bruttolistor/`** — råmaterial-listor (titel-förslag, scen-utkast, dialog-utdrag)

## Disciplin

- beslutslogg uppdateras vid varje större beslut
- öppna-frågor stängs när de besvaras (flytta till beslutslogg)
- ambition är referens för förläggare-rollen
