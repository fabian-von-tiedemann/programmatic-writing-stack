# Kvalitetsgrindar mellan faser

> Innan något passar vidare från en fas till nästa måste motsvarande grind passeras. En grind är en serie konkreta frågor som ska kunna besvaras med JA.
>
> Källa: Del III I.1-I.7.

---

## I.1 Karaktärsgrind (innan plot designas)

Innan plot-arkitekt börjar arbeta: kan jag namnge varje huvudkaraktärs

- (a) främsta önskan,
- (b) främsta rädsla,
- (c) blinda fläck,
- (d) språkliga signatur?

Om inte → karaktären är inte färdig. Plot-arbete blockeras tills character-deepening är klart.

**Ägare:** Plot-arkitekt + Världsbyggare. Verifierar mot `.context/story-graph/character-deepening/`.

---

## I.2 Plotgrind (innan kapitelplan)

Innan kapitelplan börjar: kan jag besvara

- den centrala frågan utan att se synopsis?
- inciting incident, mid-point, klimax?
- varje aktes funktion?

Om inte → plot är inte färdig. Kapitelplanen blockeras.

**Ägare:** Plot-arkitekt. Verifierar mot `.context/story-graph/threads.md` + ev. plot-outlines.

---

## I.3 Scenkortsgrind (innan prosa)

Innan writer dispatchas: har varje scen

- mål,
- konflikt,
- vändpunkt?

Vet jag POV, plats, närvarande, vad varje karaktär vill ut ur scenen?

Om inte → scenkortet är inte färdigt. Writer blockeras.

**Ägare:** Plot-arkitekt. Verifierar mot `.context/plot-outlines/kapitel-NN-outline.md`.

---

## I.4 Stilgrind (innan prosa)

Innan writer dispatchas: har jag

- exempel-stycken som visar bokens röst?
- karaktärs-röstprov per POV?
- undvik-lista?

Om inte → writer riskerar generisk AI-röst. Stilgrund saknas.

**Ägare:** Writer (egen-check) + Världsbyggare. Verifierar mot `.context/story-graph/style-guide.md` + character-deepening.

---

## I.5 Prosagrind (per kapitel, efter utkast)

Efter utkast: kan jag

- stryka tre stycken utan att förlora något?
- dölja attribueringen i dialog och fortfarande veta vem som talar?
- bekräfta att varje scen har sensorisk detalj?
- bekräfta att varje karaktär har agenda?

Om inte → kapitlet är inte färdigt för publicering. Tillbaka till fix.

**Ägare:** Redaktör + Dialog-coach. Verifierar mot manuskript + character-deepening.

---

## I.6 Boggrind (efter färdigt manuskript)

Efter manuskript: är

- alla planted clues skördade?
- alla setups paid off?
- continuity konsistent?
- alla canonical events korrekta?

Om inte → boken är inte färdig. Tillbaka till plot-arkitekt eller redaktör.

**Ägare:** Förläggare + Graf-vakt. Verifierar mot clue-economy + foreshadowing-payoff-tracker + canon.

---

## I.7 Seriegrind (efter bok N, innan bok N+1)

Efter bok N: bryter ingenting

- canonical events från bok 1–(N-1)?
- avancerar tematiska bågar?
- lämnar tillräckligt öppet för bok N+1?

Om inte → serien har drift. Stoppa innan bok N+1.

**Ägare:** Världsbyggare. Verifierar mot `.context/world-bible.md` + `.context/series-bible.md`.

---

## Sammanfattning — vilken grind tillhör vilken fas

| Fas | Grind | Ägare |
|---|---|---|
| FAS 0 (karaktärer) | I.1 Karaktärsgrind | Plot-arkitekt + Världsbyggare |
| FAS 0 (plot) | I.2 Plotgrind | Plot-arkitekt |
| FAS 0/1 (scenkort) | I.3 Scenkortsgrind | Plot-arkitekt |
| FAS 1 (stil) | I.4 Stilgrind | Writer + Världsbyggare |
| FAS 3 (per kapitel) | I.5 Prosagrind | Redaktör + Dialog-coach |
| FAS 4 (helhet) | I.6 Boggrind | Förläggare + Graf-vakt |
| Mellan böcker | I.7 Seriegrind | Världsbyggare |

Grindar är **icke-förhandlingsbara**. Ett blocket pass kräver att grindens frågor besvaras med JA innan nästa fas startar.
