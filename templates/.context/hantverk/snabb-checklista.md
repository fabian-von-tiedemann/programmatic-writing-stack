# Snabb-checklista — innan ett kapitel går från utkast till "klar"

> 17 kontroller. Tar ungefär 15 minuter per kapitel. Ägs primärt av redaktör + prosa-städ, men writer kan självgranska före submission.
>
> Källa: Del III L.

---

- [ ] Scenens fråga ställd vid öppning och besvarad/transformerad vid slut?
- [ ] Sensorisk detalj som inte är visuell?
- [ ] POV konsekvent?
- [ ] Varje karaktär har en agenda?
- [ ] Subtext > text i dialog?
- [ ] Meningsrytmen varierad?
- [ ] Inga adverb som modifierar svaga verb?
- [ ] Inget exposition-dump?
- [ ] Sensorisk ankare i öppningen?
- [ ] Karaktärsdistinkt språk?
- [ ] Inga metaberättarrösts-fraser?
- [ ] Klocka/threat synlig om relevant?
- [ ] Setups planterade noterade i tracker?
- [ ] Payoffs noterade i tracker?
- [ ] Continuity inte bruten?
- [ ] Slutet får läsaren att vilja vända blad?

**Sjutton kontroller.** Om en kontroll inte är JA — fix innan kapitel godkänns.

---

## Användning

- **Writer:** kör som självcheck FÖRE submission. Sparar tid i redaktör-passet.
- **Redaktör:** kör som obligatorisk lista vid varje kapitel-pass. Inga undantag.
- **Prosa-städ:** referera vid naiv-läsare-pass — om en kontroll var "JA" enligt redaktör men du upplevde nej, flagga.

## Operationalisering

Varje rapport (redaktör, prosa-städ) ska eksplicit besvara denna lista med JA / NEJ / N/A. Vid NEJ: citat + radnummer + förslag.

Vid samtliga JA: kapitlet kan passa till nästa fas. Vid något NEJ: tillbaka till fix.

## Pekare

- Detaljerad teknik per kontroll-punkt: `.context/hantverk/tekniker.md` (sektion A-G)
- Anti-mönster att undvika: `.context/hantverk/anti-monster.md`
- Kvalitetsgrindar mellan faser: `.context/hantverk/kvalitetsgrindar.md`
