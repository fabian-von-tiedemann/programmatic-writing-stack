# .context/ — Programmatic Writing Stack v1.2

Allt utom själva manuskriptet bor här. Strukturen är **Lager 1-7** plus rapporter, roller, process, canon, tools, hantverk.

## Lager (designordning)

1. **Koncept** (`koncept/`) — premiss, logline, genre, form, kontrakt, central-fråga, teman
2. **Värld** (`varld/`) — tidsperiod, geografi-grund (kompletteras av locations.json + research-dossier/)
3. **Karaktärer** (`story-graph/` + `character-deepening/`) — canon + fördjupningar
4. **Plot** (`plot/`) — struktur, bågar, kapitelplan, scenkort, clue-economy, klocka, informationsflöde
5. **Research** (`research-dossier/`) — verifierad fakta per ämne
6. **Stil** (`stil/`) — POV, dialog, motiv, rytm, inspiration, platser
7. **Förlag** (`forlag/`) — respons, beta, formatering, loglinetest, revisions-tracker
