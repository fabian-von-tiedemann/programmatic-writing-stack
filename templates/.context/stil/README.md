# stil/ — Lager 6

> Prosastilens regler. Per POV, per dialog, per motiv, per rytm. Inspirations-författare. Plats-beskrivnings-canon.

## Filer

- **`pov.md`** — POV-regler (vilken person, distans, free indirect, läckage-spärrar)
- **`dialog.md`** — dialog-regler (talstreck, sa-verb, subtext, per-karaktär-röst)
- **`motiv.md`** — återkommande motiv + symboler i prosan (kopplad till `koncept/teman.md`)
- **`rytm.md`** — meningsrytm, paragraf-rytm, kapitel-rytm

## Underkataloger

- **`inspiration/`** — per författare/bok: vad ska imiteras + vad ska INTE imiteras
- **`platser/`** — per plats: stilistiska val (sensorik, ton, vinkel)

## Disciplin

- Stil-regler är hårda (writer-canon)
- Dialog-coach + prosa-städ verifierar mot dessa filer
- Förändring i stil = re-kalibrera tidigare kapitel (eller markera som "stil-shift v1 → v2")
