# research-dossier/ — Lager 5

> Verifierad fakta per ämne. Per ämnes-dossier: fakta + källa + relevans för boken.

## Princip

- **Canon-research** (in i grafen) — fakta som bokens karaktärer "vet" eller miljö "är"
- **Writer-bakgrund** (stannar i dossier) — atmosfär, textur, kontext som writer behöver för att förstå men inte skriver explicit

## Per dossier

Använd `MALL.md` som mall. En fil per ämnes-block.

Exempel-ämnen:
- {{Bransch — t.ex. "Polis-arbete i en mellanstor stad"}}
- {{Plats — t.ex. "Almedalsveckan — logistik och kultur"}}
- {{Fenomen — t.ex. "Deepfakes och AI-OSINT"}}
- {{Yrke — t.ex. "PR-byrå-arbete i Sverige 2025"}}

## Process

1. PLOT-ARKITEKT flaggar research-behov i FAS 0
2. RESEARCHER skapar dossier
3. Canon-fakta extraheras till grafen (events, locations, organizations)
4. Bakgrunds-textur stannar i dossier för writer-konsumtion
5. Dossier uppdateras vartefter nya fakta-frågor uppstår

## Disciplin

- Varje fakta-claim har källa
- Källor utvärderas för pålitlighet (primär > sekundär > tertiär)
- Vid motstridiga källor — flagga + besluta vilken som vinner i bokens canon
