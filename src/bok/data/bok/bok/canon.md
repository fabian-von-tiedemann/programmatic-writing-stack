# Canon

Fakta som måste hålla genom hela boken. Kontinuitet och Redaktör kontrollerar mot den här filen.

## Fakta

Skriv in sådant som måste stämma: avstånd, årtal, yrkesregler, hur världen fungerar.

## Verkliga personer som inte får förekomma

`bok validate` stoppar kapitel som nämner någon av dem. Ett namn per rad.

```blacklist
```

## Kända namn som inte är karaktärer

Namn som får förekomma utan att finnas i grafen: orter, varumärken, historiska personer. Ett per rad.

```kanda-namn
```

## Verkliga händelser

Verkliga händelser som boken använder. Finns det rader här läser sensitivitetsläsaren planen innan du ger ditt ja. En per rad: `datum | händelse | vad boken lägger till`.

```verkliga-handelser
```
