# Egna regler per roll

Rollerna ligger i mappen .claude/agents och skrivs om när ramverket uppgraderas. Vill du ändra hur en roll arbetar i just den här boken: skapa `<roll>.local.md` här, till exempel `writer.local.md`. Rollen läser filen först, och den går före standardbriefen.

Roller: `plot-arkitekt`, `writer`, `redaktor`, `sprakgranskare`, `kontinuitet`, `forlaggare`, `researcher`, `varldsbyggare`, `sensitivitet`, `audiobook`, `marknad`.
