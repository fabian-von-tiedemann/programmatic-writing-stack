# Revisioner

Det du har bestämt att ändra efter respons från lektör, betaläsare eller förlag. En rad per sak. Writer arbetar efter de öppna raderna, och Kontinuitet kryssar av det som är gjort.

Format: `- [ ] Kapitel 3: vad som ska ändras` för ett kapitel, `- [ ] Alla: vad som ska ändras` för hela boken.
